# OpenCart Website Project

This repository contains the source code for an OpenCart-based website. The project is currently **unfinished but open for further development**.

## About the Project

This project is **live on the internet** and can be viewed at: [www.morizointurkiye.com](https://www.morizointurkiye.com).

This project is primarily focused on **HTML customizations and template integration** within the OpenCart framework. Although it is still a work in progress, it provides a solid foundation for further enhancements and functionality additions.

### Current Features
- OpenCart-based structure
- Customized HTML templates
- Basic theme integration
- Ready for further development

## Technologies Used
- **Backend:** OpenCart (PHP-based)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
